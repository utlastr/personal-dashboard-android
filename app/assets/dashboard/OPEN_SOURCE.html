ActivityWatch

本应用复用 ActivityWatch aw-server-rust 的安卓二进制引擎，并将 aw-android 的前台会话状态机移植为 Java，补充屏幕关闭与关机边界。上游版本：aw-android v0.14.3。修改部分保留 MPL-2.0 许可证。

源码来源：https://github.com/ActivityWatch/aw-android/tree/v0.14.3
数据引擎：https://github.com/ActivityWatch/aw-server-rust/tree/af70e58d97cde37bb004886cec095c466e97fe6b
本应用源码与对应版本的源码压缩包发布于：https://github.com/utlastr/personal-dashboard-android/releases

界面资源来自现有 Personal Dashboard，底层 Web UI 来自 ActivityWatch aw-webui（MPL-2.0）。
