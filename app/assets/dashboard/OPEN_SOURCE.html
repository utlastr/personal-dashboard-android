ActivityWatch

Personal Dashboard uses the ActivityWatch aw-server-rust Android binary and ports the aw-android foreground session tracker to Java with screen-off and shutdown handling. Modified code from aw-android v0.14.3 remains licensed under MPL-2.0.

Android source: https://github.com/ActivityWatch/aw-android/tree/v0.14.3
Engine source: https://github.com/ActivityWatch/aw-server-rust/tree/af70e58d97cde37bb004886cec095c466e97fe6b
Dashboard source archives: https://github.com/utlastr/personal-dashboard-android/releases

Interface assets come from Personal Dashboard. The underlying web UI comes from ActivityWatch aw-webui (MPL-2.0).
